# Contributing to InteractEmbed Creator

Contributions must follow the Moodle coding style and preserve the publication
contract shared with `mod_interactembed` and `block_interactembed`. Changes to
package structure, context visibility, permissions, iframe isolation or signed
resource delivery must be coordinated with both consumer plugins.

Run PHP lint, Moodle Plugin CI, PHPUnit, JavaScript, CSS, Mustache, PHPDoc and
Code Checker validation before proposing a release. Never commit credentials,
learner data, session cookies or private HTML5 packages.

Report defects and feature requests in the
[public issue tracker](https://github.com/InteractEmbed/moodle-local_interactembedcreator/issues).
