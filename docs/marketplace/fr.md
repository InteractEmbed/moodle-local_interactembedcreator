# Creator InteractEmbed

## Description courte

Créez dans Moodle des présentations HTML5 interactives, accessibles et
réutilisables, puis publiez-les dans l’Activité et le Bloc InteractEmbed.

## Description complète

Creator InteractEmbed est une bibliothèque de création Moodle pour des
présentations HTML5 interactives au format 16:9. Son éditeur visuel permet de
combiner textes, images, sons, vidéos, boutons, quiz et parcours avec
embranchements, sans programmation.

Les projets peuvent appartenir au site, à une catégorie ou à un cours. Une
publication produit un paquet immuable sélectionnable depuis l’Activité ou le
Bloc InteractEmbed. Les projets de cours suivent la sauvegarde et la
restauration Moodle; les ressources partagées du site et des catégories restent
indépendantes. Un vérificateur d’accessibilité et un guide interactif sont
inclus.

Creator exige l’Activité et le Bloc InteractEmbed. Ces deux plugins peuvent
toutefois fonctionner indépendamment de Creator. Aucun service externe,
abonnement, clé API ou outil de compilation n’est nécessaire sur le serveur.

## Installation

1. Installer l’Activité InteractEmbed 1.0.0.
2. Installer le Bloc InteractEmbed 1.0.0.
3. Installer Creator InteractEmbed 1.0.0.
4. Terminer la mise à niveau Moodle et vérifier les permissions des rôles.

Versions Moodle prises en charge : 4.5 à 5.2.
